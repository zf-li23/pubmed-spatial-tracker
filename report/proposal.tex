\section{一、选题背景与意义}

生物医学文献正以指数速度增长：以空间转录组学为例，PubMed年发文量从2010年不足20篇激增至2025年2,638篇。自动文献分类面临三重挑战：(1)~文本稀疏，词袋模型无法捕捉医学术语语义关联；(2)~标签空间复杂，一篇文献同时涉及研究类别、生物领域、技术平台和分析方法，构成多标签问题；(3)~标注成本极高，大规模标注不现实。

本课题在两个数据集上系统比较多策略机器学习方法：(1)~自建的 PubMed Spatial Tracker\footnote{代码仓库：\url{https://github.com/zf-li23/pubmed-spatial-tracker}，含PubMed检索、规则引擎、Web标注界面、ML管线及主动学习流程。} 空间转录组学文献库（7,029篇，含领域精细化标签体系）；(2)~OHSUMED\footnote{\url{https://trec.nist.gov/data/filtering/t9.filtering.tar.gz}}基准数据集（348,566篇，MeSH多标签标注）。两个数据集覆盖类别多分类、多标签预测与主动学习三个核心问题，支撑贝叶斯学习、集成学习、深度学习、无监督学习、生成式模型、基于实例的学习等全部课程模块的主流算法系统比较。

我是生命学院生物信息学方向的学生，本项目最初受课程作业一启发，为服务于我日常科研中的文献阅读需求而建立，不属于任何课程或SRT项目。

\section{二、拟采用的特征与算法}

\subsection*{2.1 文本表示（4种）}

\begin{itemize}
  \setlength{\itemsep}{0pt}\setlength{\parsep}{0pt}
  \item \textbf{TF-IDF}：1--2~gram，max\_features=5,000，稀疏表示基线。
  \item \textbf{BioBERT}：\verb|dmis-lab/biobert-base-cased-v1.1|对标题+摘要+MeSH拼接文本做mean~pooling（768维）。
  \item \textbf{LDA}：全库文本做Latent~Dirichlet~Allocation（$K=15$），每篇文献表示为主题分布向量。
  \item \textbf{元特征}：出版年份、期刊类型、MeSH存在标志，拼接至上述向量末端。
\end{itemize}

\subsection*{2.3 主动学习（3种策略）}

\begin{itemize}
  \setlength{\itemsep}{0pt}\setlength{\parsep}{0pt}
  \item \textbf{不确定性采样}：基于SVM margin $1-|P_{\max}-P_{\text{second}}|$，选最不确定样本。
  \item \textbf{熵采样}：基于预测概率分布的香农熵 $-\sum_i P_i\log P_i$。
  \item \textbf{委员会查询}：多分类器投票分歧度（RF、SVM、XGBoost预测不一致的样本优先）。
\end{itemize}
迭代流程：初始50篇 $\to$ 选20篇 $\to$ 重训 $\to$ 循环10轮。随机采样作为基线。

此外，针对空间转录组学文献的每类别合法标签空间约束策略（如Review仅1个domain标签、Technology最多2个技术标签），通过消融实验量化领域知识收益；OHSUMED以MeSH层级约束作为类比。

\section{四、评价方案与预期结果}

\subsection*{4.1 评价指标}

类别分类：Accuracy, Macro/Weighted~F1, Cohen's~$\kappa$；多标签：Jaccard, Hamming~Loss；主动学习：达85\%~F1标注量、学习曲线AUC；跨数据集：迁移F1差异。

\subsection*{4.2 预期结果}

\textbf{(1)~算法排序}：BioBERT+MLP~$>$~XGBoost~$>$~LightGBM~$>$~RF~$>$~SVM~$>$~AdaBoost~$>$~LR~$>$~$k$-NN~$>$~NB。GPT-4o零样本在常见类别准确率高、罕见类别急剧下降，暴露LLM尾部知识盲区。

\textbf{(2)~约束策略}在Spatial Tracker上提升标签F1~8--12\%（纠正跨组误报），OHSUMED上利用MeSH层级提升3--5\%。

\textbf{(3)~主动学习}委员会$>$熵$>$不确定性$>$随机基线，节省40--60\%标注量。OHSUMED大规模验证排除小样本偶然性。

\textbf{(4)~迁移学习}双数据集共享PubMed格式，预期迁移F1损失$<$15\%。
